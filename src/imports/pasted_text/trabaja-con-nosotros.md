==================================================

The form must:

1. Validate all required fields.
2. Validate email format.
3. Validate date of birth.
4. Validate required checkbox.
5. Validate file types.
6. Validate file sizes.
7. Upload the 2x2 photo.
8. Upload the CV.
9. Save the applicant's data in Supabase.
10. Associate uploaded files with the correct applicant.
11. Show a success confirmation.
12. Show clear validation errors.
13. Prevent duplicate accidental submissions.
14. Show loading state while submitting.
15. Reset the form only after successful submission.

Suggested data structure:

applications

- id
- first_name
- last_name
- national_id
- birth_date
- email
- phone
- desired_profile
- photo_path
- cv_path
- requirements_confirmed
- privacy_consent
- created_at
- status

Use appropriate Supabase Storage buckets for uploaded files.

IMPORTANT SECURITY REQUIREMENTS:

Do NOT expose Supabase service_role credentials in frontend code.

Do not make applicant files publicly accessible.

Use private storage buckets and secure access policies.

Use Row Level Security where appropriate.

Use server-side validation for sensitive submissions.

Never place sensitive credentials directly in the client-side code.

The application form contains personally identifiable information, therefore treat it as sensitive data.
